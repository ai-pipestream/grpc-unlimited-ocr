41b7100a482de9d26513fddfded96aad454f61ea.

## Native build and kernel/model parity

The native service, runner and Metal test executables built successfully,
including `UOCR_WERROR=ON`. The original primitive GEMM test passed in
0.28 seconds. The final ops, tiled vision and decoder tests passed in
1.19 seconds total, including the deferred-buffer lifetime and cap checks.
The decoder test compares prefill and 44 decode steps against the reference.
Raw values are in `metal-m2-20261108/tiny-parity-final.txt`.

The first implementation inherited CUDA's bf16 activation narrowing and
failed a later decoder step. Retaining fp32 activations removed the failure
without loosening the 2e-2 tolerance. Upstream weight bits remain bf16.

Linux non-Metal regression build: 10 tests executed, 4 model-dependent
tests skipped, no failures (2.35 seconds). This is host regression evidence.

## Real golden page, two sequential runs

The model produced exact golden text and labels, six boxes with **zero**
coordinate difference and 171 identical tokens on both runs. Both runs
completed with EOS. All retained-allocation assertions passed.

| Measurement | First run | Second run |

| Vision plus prefill, seconds | 23.840 | 18.420 |
| Decode, seconds | 33.304 | 25.561 |

| MPS GEMM dispatches | 53,264 | 53,264 |

Total test wall time including startup/loading was 139.36 seconds.
System-wide memory was 45% free during the second run. RSS does not fully
account for shared GPU allocations; use the Metal allocation figures too.
An ASR compilation could overlap this run, so these are observed timings,
not an isolated performance baseline. The raw receipt is
`metal-m2-20261108/golden.txt`.

## Still in progress

Actual RPC repeat/cancel/recovery qualification is running with the shared
harness from `0c7df82890c8a74c22ac3b7e38ec44f71681ae99`. It has not yet
passed. A same-Mac sequential CPU comparison has not run. Neither is
claimed by the direct-model golden result.

Implementation limits: no-copy weight mapping and indirect-command-buffer
replay are not implemented. Host preprocessing, prompt assembly, grouping
metadata and generation policy remain host-side; neural-network arithmetic
runs through Metal kernels or MPS GEMM. Cancellation is observed at decoder
token boundaries; initial vision/prefill is not preemptible.
