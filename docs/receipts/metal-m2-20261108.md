# Apple M2 native Metal qualification

Native arm64 Apple M2, 24 GiB, macOS 27.2 build 26B123; AppleClang 21,
CMake 4.4.4, system gRPC 1.85.1 and protobuf 36.2. Starting commit:
41b7100a482de9d26513fddfded96aad454f61ea.

Actual source pins were checked on the Mac after the golden run:

- stb: `003501f6d7a8668ce8b6d875e34dd97ad0d5d5b5`.
- JSON: `55f93686c01528224f448c19128836e7df245f72`, tag `v3.12.0`.
- FetchContent source overrides are empty; disconnected mode is off.
- gRPC/protobuf are explicitly the installed native packages above, using
  `UOCR_SYSTEM_GRPC=ON`, not the default fetched gRPC 1.83.0.
- The transferred source archive's digest is in
  `metal-m2-20261108/native-source-archive.sha256`. A per-file source
  manifest was additionally checked before the RPC build.

Both upstream shards and all six accompanying files passed SHA256 checks
after copying to the Mac. No converted weights were written.

## Native build and kernel/model parity

The native service, runner and Metal test executables built successfully,
including `UOCR_WERROR=ON`. The original primitive GEMM test passed in
0.28 seconds. The final ops, tiled vision and decoder tests passed in
1.19 seconds total, including the deferred-buffer lifetime and cap checks.
The decoder test compares prefill and 44 decode steps against the reference.
Raw values are in `metal-m2-20261108/tiny-parity-final.txt`.

The first implementation inherited CUDA's bf16 activation narrowing and
failed a later decoder step. Retaining fp32 activations removed the failure
without loosening the 2e-2 tolerance. Upstream weight bits remain bf16.

Linux non-Metal regression build: 10 tests executed, 4 model-dependent
tests skipped, no failures (2.35 seconds). This is host regression evidence.

## Service streaming and actual TCP cancellation/recovery

The shared `0c7df82890c8a74c22ac3b7e38ec44f71681ae99` harness passed six
alternating one/two-page requests with Metal/bf16 explicitly selected.
This version used an **in-process gRPC channel** and direct-core recovery;
it does not qualify TCP recovery. Total wall time was 367.01 seconds,
peak RSS 5,985,271,808 bytes and peak process footprint 7,456,778,440 bytes.
Offline comparison found exact repeated emitted block text, labels,
coordinates and raw token text across the three requests of each size.
Numeric token IDs were not printed by this harness. Receipts:
`metal-m2-20261108/rpc-inprocess.txt` and `rpc-repeat-check.txt`.

The corrected common harness `d978a13a4dea8dd23ee8a7d5c4efb99323f1ed11`
was imported as `8913a2d`, with a separate `--cancel-only` mode in
`48abee7c345bbcf5391b5973d49ad1f63f2514dd`. This mode skips the six initial
requests and retains all three cancellation/recovery cycles. All three
cycles passed over **127.0.0.1 TCP gRPC**, including valid raster input,
prefill completion, CANCELLED status, admission release, subsequent real
content/boxes/tokens/fragments/completion checks and final lease release.
Total wall time was 169.65 seconds, peak RSS 6,169,870,336 bytes and peak
process footprint 7,441,311,968 bytes. No other model was resident.
Receipt: `metal-m2-20261108/rpc-tcp.txt`; tested source manifest:
`metal-m2-20261108/tcp-source-files.sha256`. All manifest entries passed
on the Mac. The service and client ran in the same process using a real
loopback TCP connection; this is not a separate-process deployment test.

## Review hardening

After the TCP run, parent cap configuration was adapted in `7fc7cef`,
and dtype validation plus pending-command draining in `410b20f`. Native
service/runner/test rebuild passed with WERROR. Five targeted tests passed
in 1.15 seconds, including a sticky-error injection while a command still
references a retired buffer. The command completed before storage release,
its output remained correct and the error remained sticky. Unknown dtype
values fail before allocation. Receipt: `review-tests.txt`.

An actual Metal model startup with `GRPC_UOCR_DEVICE_MEMORY_CAP=1048576`
failed as expected with exit 1 and `Metal allocation exceeds cap`.
Configuration tests reject nonzero caps for unsupported backends. The
default remains 12 GiB. Full-model TCP results above predate these review
changes; the successful normal numerical paths also passed the final tiny
ops, vision and decoder tests. `final-source-files.sha256` passed on the Mac.

## CPU comparison in progress

The same-Mac reference runner is executing sequentially with two CPU
threads and nice 10. Before launch, no model process remained and system
memory was 74% free. A watchdog enforces 900 seconds, 17 GiB RSS and a stop
if system free memory falls below 12%. No performance comparison is yet
claimed.

Implementation limits: no-copy weight mapping and indirect-command-buffer
replay are not implemented. Host preprocessing, prompt assembly, grouping
metadata and generation policy remain host-side; neural-network arithmetic
runs through Metal kernels or MPS GEMM. Cancellation is observed at decoder
token boundaries; initial vision/prefill is not preemptible.
